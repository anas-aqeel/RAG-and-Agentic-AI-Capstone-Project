# Final Submission Gallery

Consolidated capstone deliverable — the screenshots IBM's grader uses to evaluate the project. Filenames follow the pattern `M{module}L{lab}_{topic}.png`.

- **`questions/`** — IBM-provided question screenshots showing what each lab's expected output should look like.
- **`answers/`** — User-generated answer screenshots proving the exercise was completed.

The two folders mirror each other 1-to-1: every `questions/<name>.png` has a matching `answers/<name>.png`.
